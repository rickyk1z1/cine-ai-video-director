# cinematic-storyboard

把想法、剧本或已有视频，推进到能实际制作和返修的分镜与 AI 视频素材。它会帮你推敲文字分镜和镜头衔接，选视觉方向，整理角色、场景与分镜图；图稿确认后检查整段是否讲得通，并建议各镜头怎样生成更合适。随后准备平台可读的提示词与素材，拿到视频再针对问题局部修改。

**通常这样做：**说出想法或提供剧本 → 推敲分镜 → 制作并确认分镜图 → 检查整段逻辑并选择生成方式 → 准备平台输入 → 看结果并局部修改。手上已有分镜、图片或视频时，直接从需要处理的地方开始。

## 开始使用

此仓库为私有仓库。先确保本机的 Git 能访问它，并安装 Node.js 20+；运行工作台还需要 Python 3.10+ 和浏览器。然后执行：

```sh
npm exec --yes --package=github:rickyk1z1/cinematic-storyboard#v3.0.0 -- cinematic-storyboard-install
```

安装器会选择现有的同名 Skill 位置；新安装放在 `~/.agents/skills/cinematic-storyboard`。遇到两个现役副本或无法确认是否含本地修改时，它会停止并保留原文件。安装后新开一个 Codex 对话；若 Skill 尚未出现，重启 Codex。然后可以说：“用 cinematic-storyboard 帮我把这个故事做成分镜。”也可以说：“我已有视频，帮我找出哪里需要返修。”想自行打开工作台，见[使用说明中的启动命令](docs/USAGE.md#自行打开工作台)。

平台账号和生成工具由使用者自行准备。若约定由你点击生成，助手只把提示词与素材放到对应节点并核对，不代你提交。具体用法见[使用说明](docs/USAGE.md)，运行条件见[移植与运行条件](references/portability.md)；实际制作规则以[SKILL.md](SKILL.md)为准。

内置视觉图库保留了图片的来源记录，供有仓库访问权的成员内部参考；图片不随此仓库授予公开转载或再分发许可。来源可在[图库数据](assets/visual-style-atlas/atlas.json)中查看。
