# 使用 cinematic-storyboard

给出作品要表达的内容，以及现有的剧本、图片或视频即可。不必先填一整套表。可以这样开始：

> 用 cinematic-storyboard 帮我做一条短片。我想让观众先看到一个普通物件，再发现它其实通向另一个空间。请先和我推敲分镜。

助手会先把故事的观看顺序、每组镜头要交代的信息和衔接讲清楚，再按需要进入视觉定调、资产与分镜图。图稿都确认后，它会预演一次整段图序，指出缺镜、逻辑断点和可能难以生成的动作，并给出逐镜或分组的生成建议。你可以选择直接上平台，也可以先做必要的预演。

例如，画到中途发现人物从门外直接跳到屋内，少了开门这个过程。此时直接补上相关镜头，同时改好文字分镜和相邻分镜图；不必退回文字阶段重新确认整段。图稿确认后的整段审查只做一轮。若你按建议调整了两镜，助手更新受影响的生成方式和平台输入，然后继续制作。

生成前，助手会按实际平台整理提示词、参考素材、镜头顺序和声音安排。是否由助手提交，按这次约定执行；如果你负责点生成，助手准备并回读节点后就停下。看到结果后，指出具体问题和时间区间即可，例如“第三个镜头的手部动作不自然”。助手会保留有效镜头，只返修受影响部分，并交代如何与前后内容接上。

已有文字分镜可从补图或检查衔接开始；已有成片可直接从诊断与返修开始。工作台用于查看镜头、图稿和建议，项目文件仍保存在你指定的项目目录。完整方法与边界见[SKILL.md](../SKILL.md)。

已有材料时也可以直接说：“请读取这份分镜，先检查镜头衔接并指出要补的图。”或“请看这条样片的 8–12 秒，人物过门时位置跳变；保留其他镜头，给出局部返修方案。”

## 自行打开工作台

通常让 Codex 在项目对话中打开即可。若要自己启动，先把下面的 `SKILL_DIR` 改成安装器实际输出的路径；新安装默认是示例中的位置。把 `PROJECT_DIR` 改成你希望保存分镜的目录：

```sh
SKILL_DIR="$HOME/.agents/skills/cinematic-storyboard"
PROJECT_DIR="$PWD/my-storyboard"
python3 "$SKILL_DIR/scripts/storyboard.py" create --directory "$PROJECT_DIR" --title "示例分镜"
python3 "$SKILL_DIR/scripts/storyboard.py" open --directory "$PROJECT_DIR"
```

`create` 会在指定目录创建一个空白分镜项目。`open` 返回本机工作台地址，在浏览器打开后，点击顶部“视觉定调”就能查看图库。已有项目不必再运行 `create`，直接运行 `open`。

结束本次工作台服务时运行：

```sh
python3 "$SKILL_DIR/scripts/storyboard.py" stop --directory "$PROJECT_DIR"
```
