# 按需视觉定调库

`atlas.json` 是条目和来源真源，`atlas-data.js` 与 `视觉风格图鉴.md` 由 `python3 tools/rebuild_views.py` 生成。图片保持相对路径，个人离线浏览；不复制成各项目图库。

工作台“更多操作 → 视觉风格参考”可打开页面。助手按实际简报传入 `?recommend=natural,ink,cgtoon,clay,collage`，具体编号按本次取舍；不带参数的默认卡仅为浏览起点。执行方法见 [风格选择与落实](../../references/style-development.md)。

示例图只用来理解视觉特征；来源、人物、构图与制作参数不自动成为当前项目的生成要求。图库不提交媒体生成，也不自动采用任何方向。选定内容写回当前项目已有的 style 记录。
