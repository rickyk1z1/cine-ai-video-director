# 摄影设计：景别、视角、构图与运动

当取景、空间投影、视觉重点或摄影运动需要推敲时读取。术语用于沟通，无法确定画面时补实际关系，不用更多术语堆出“电影感”。选择服从当前观看意图，分类与技术数值不作为创作配额。

## 景别与取景范围

中文与英文分类不完全对应，各项目也可能有不同口径，已有定义时沿用。下表是取景参考，不要求用齐。

| 常用名称 | 常见英文 | 人物取景参考与用途 |
|---|---|---|
| 大远景 | Extreme long shot / Extreme wide shot | 人在环境中很小；看尺度、布局或人的处境 |
| 远景 | Long shot / Wide shot | 人与较大范围环境同时可见；辨认行动关系 |
| 全景 | Full shot | 完整人体与必要活动空间；看身体动作和站位 |
| 中远景 | Medium long shot | 大约膝部以上；兼顾姿态、手部与交互 |
| 中景 | Medium shot | 大约腰部以上；交谈、双手操作与关系 |
| 中近景 | Medium close-up | 大约胸部以上；保留部分身体反应 |
| 近景 | Tight medium close-up | 头肩或肩部以上；不同中文体系可能并入特写 |
| 特写 | Close-up | 面部或主要物件占显著面积；读具体信息 |
| 大特写 | Extreme close-up | 眼睛、指尖或结构局部；强化细节同时隐去环境 |

双人、群像、过肩、主观、插入镜头不是额外景别档位；双人镜头也可以是近景。微距描述成像尺度和拍摄能力，不等同于“大特写”一词。

选择需要的观察距离，连同前后镜头一起判断。特写能让微表情易读，也可能显得疏离；远景能说明布局，也可能强化孤独。丰富不是交替套用大小景别，稳定同框有作用时保留，需要细节或关系时也不吝惜切镜。

## 机位、视角与透视

分别明确摄影机位置、高度、朝向与俯仰角。低机位水平拍不是仰拍，高处水平拍也不是俯拍。视角的效果来自对象、行为与画面关系，不把低角度固定解释为强大、俯视固定解释为弱小。

过肩保留观察者和距离，干净单人镜头能隔离人物但可能丢失关系。主观镜头由人物实际位置、眼高与朝向推导；反打或换机位重新计算看见的背景、遮挡和受光面，前镜的屏幕左右不能直接继承。具体成对判断见[机位与背景组接](continuity-review.md#相邻切镜的机位与背景组接审查)。

透视由摄影机与对象的相对位置决定。同取景范围下，短焦近拍与长焦远拍会改变前后对象的相对尺度；只给焦距数值不能让模型自动理解空间。技术焦距有实际用途时说明传感器/等效口径，未知则描述希望出现的视觉关系，不伪造精确参数。

## 构图与光线如何支持动作

先决定此刻必须看清什么，再安排位置、尺度、明暗、色彩、清晰范围、遮挡与运动。主角不必居中，留白也不必永远朝目光方向；例如把人物留在边缘，让门外空处承载期待，应能从观看中感到其作用。

前中后景可以同时承载人物关系。深焦允许比较不同层的动作，浅景深集中注意，移焦改变清晰对象而不移动摄影机。多中心画面区分必须识别与可自由发现的内容，不能假设观众同时读清小字、微表情和远景细节。

用可执行光线关系说明形体与重点，如光源方向、软硬、主体与背景亮度关系。产品尤其检查轮廓、结构与材质可读性；“高级光影”不够。光色含义由本片建立，不硬套颜色情绪；换机位时保持光源的空间依据，不要求亮面永远留在画面同侧。

## 运动的选择

| 方法 | 可以服务的观看目的 | 需说明的关系 |
|---|---|---|
| 固定 | 等待、完整表演、图形秩序与对照 | 画内变化或形式如何支撑停留 |
| 推近／后退 | 集中注意、改变距离、揭示环境 | 起止位置、透视变化与何时看清重点 |
| 横移／跟随 | 陪伴人物、揭露遮挡后空间 | 摄影机方向、主体方向、视差与遮挡 |
| 摇／俯仰 | 在位置间转移注意、垂直揭示 | 是转动而非平移；从何处转向何处 |
| 升降／环绕 | 观察体积、改变高度、显露布局 | 路线、净空、轴线与背景投影 |
| 变焦 | 改变取景范围、强调观察行为 | 与摄影机实际位移分开 |
| 手持／稳定跟拍 | 身体参与、临场观察或平稳陪伴 | 运动动机与稳定程度，不以抖动保证真实 |

复合运动可以保留，写清主要路径、主体配合、注意转移与停止条件；不是把推、摇、升、环绕全列出来就可执行。真实摄影机需要能通过的空间，非现实机位需要明确可感知的变换与制作方式。遇到冲突先比较改调度、改观看时序或真实切镜，按[逐镜可执行性](shot-readiness.md)完成判断。
