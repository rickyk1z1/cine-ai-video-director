# 最新分镜交接为生图提示词

先用工作台读取最新保存版本，核对哪些内容已被用户修改。镜头设计是输入依据；图像模型不应替分镜决定镜头次序或新增关键剧情。

## 交接前复核

先执行[逐镜可执行性复核](shot-readiness.md)。读取最新稿不等于可交接：隐含切镜、时间不足、机位/动作矛盾未解决时，明确指出镜号和处理方式，不输出貌似可直接执行的提示词。已有提示词current仅表示内容依赖未变，不代表设计可靠。

图像提示词从每镜选择具体静态时刻，视频交接则保留已明确的镜号、顺序、切点和时段。一个生成包覆盖多镜时，不能把真实切镜拼成含糊的连续镜头；同一连续镜头有多个状态图时，也不能把图号升级为镜号或切点。工具不支持时先调整分包或回到分镜设计，不能默认模型自动切镜。

## 选择交付粒度

- 先沿用项目已定画幅；尚未确定时在生图前问一次。同一项目不重复询问。画格比例、宫格整图比例和输出视频比例分别判断，不把本次画幅写成通用规则。
- 单镜图：适合关键构图、局部修改或需要独立检验的复杂动作。
- 镜头组多格图：适合一组镜头需要一起观察其动作发展、视点与连续关系。
- 整段分镜板：适合审阅节奏和内容覆盖；格数由已确定分镜决定，不为网格补无意义画面。

同尺寸、同画幅的画格与整张拼版保持相同画幅时，2×2四宫格和3×3九宫格最容易准确排版。默认在相邻、适合一同阅读且缩小后仍清楚的镜头中选4格或9格，剩余镜头用单图，不填空白格：5镜可为4＋1，8镜可为4＋4，13镜可为9＋4，但不为凑数跨过无关镜头。这里数的是画格；4＋1是五个画面、两个实际参考文件。长镜头另需起终或中间状态时，使用同镜号的补充状态图，不把状态数冒充镜头数。用户指定逐镜单图时全部分开。

宫格可让图像模型一次画整板，也可把已采用单镜图用 `grid.py compose` 确定性排版；按连续变化、身份/构图精度、已有图与修订成本选择。排版不重画图，整板生成后逐格检查并登记实际裁切范围。上传入口限制在图稿定稿后核对，必要时只适配上传副本或补所需状态图，不因平台规格重做已认可创意。

数量、尺寸和输入参考数量依实际工具能力核对。多个镜头可以共用一份提示词，一个动态镜头也可以需要多个静态时刻。既不默认全部独立生成，也不默认整段必须一次生成。

## 从动作过程选一个时刻

根据用途选择开始、转折、高潮或结束状态。关键帧应代表这一镜要表达的关系。运镜起终点差异很大时可交付两帧并注明属于同一镜头，不谎称单幅静帧展示完整摄影机路线。

图片文字描述应能回答：在哪里、谁在做什么、此刻动作完成到哪里、摄影机从哪里看、画面包含什么、不包含什么。详细程度以避免误解为准。不要同时要求同一个角色正在进门、坐下并喝完茶。

## 让每格画面承担明确的观看任务

从已定分镜和视觉风格判断：当前画格要让观众先注意哪里，读清哪个人物、动作关系或关键信息。同镜多状态按各自时刻分配，不要求一张静帧提前展示后续结果。氛围、风景和抽象镜头也可以让空间层次、光色或形态变化成为重点，不强行安排居中人物或唯一焦点。选择能呈现这一重点的机位、景别和静态时刻，再从主体尺度、遮挡、视线与画面线条、留白、光线和清晰范围中找出影响可读性的因素。只写本格真正需要的视觉选择；沿用已认可的风格，不机械给每格套同一构图或“电影感”词汇。

这些判断用于选择画面和审查结果，不另建必填栏目。已有分镜或采用参考足以表达时直接承接；若要改变已确认的观看重点或拍法，先回分镜核对，而非让生图提示词自行改剧情。

## 组织提示词

提示词包在内部记录修订与覆盖镜头。正文遵循[完整表达与去冗余](prompt-constraints.md#面向生成模型的完整表达与去冗余)，以下是按需选择的信息，不是必填栏目；同一事实只写一次：

1. 影片视觉基调和当前段落的具体内容。
2. 引用资产及作用：哪张锁定人物身份，哪张确定场景布局，哪张只参考材质或色彩。
3. 单幅构图或逐格内容：景别、观察角度、主要位置、动作时刻，以及引导当前画格观看重点所需的光线、清晰范围等实际选择。
4. 共用且不可随意改变的身份、服装、道具、空间状态；本镜允许改变的表情或机位。
5. 画幅、分格方式，以及文字、编号、说明的处理方式。

多格图明确阅读顺序和镜号对应。中文品牌、UI或精确文字是否后期处理沿项目约定；不把图像模型文字能力当确定性排版保证。需要实物参考而尚缺时，标为探索性画面，不把猜测升级为已认可资产。

## 修改与验收

按[连续性与跨输入校准](continuity-review.md)在生成前确定相邻状态、出图后查看实际画面、整段图齐后核对全部接点。采用白模时，构图图与白模帧相互校准；修正后的输入不能继续引用相冲突的旧机位图。

用户修改某镜后，复核直接关联提示词与依赖同一动作状态的相邻镜头。共用角色、场景或主基调变化可能影响更多镜头，应列出影响范围；无关提示词不重做。

文字设计检查关注提示词是否忠实于已定分镜，也要看观看重点能否落到具体画面选择。出图后按实际画格和宫格审阅尺寸观看：观众先看见什么，关键信息与动作关系是否清楚，再核对身份、空间、光线、构图和相邻接点。内容正确但重点被背景、遮挡或不合适的景别淹没时，定位是分镜设计还是图片实现的问题，只修受影响的镜头和参考；不靠补“更电影感”等空泛词汇掩盖。图片通过也不等于动态动作、口型、实物交接或现场播放通过。

在本批方案已有制作授权时，使用当前任务已选且可用的生图工具并遵守其说明；沿[制作物料包](production-package.md)先完成缺失资产的制作与集中采用，再制作分镜图并集中审阅。资产批次内部的新候选可作标记清楚的临时基准，不在每张母图或状态图后追加确认；进入正式分镜图时只引用已采用且适用的资产。接口未提供模型确认信息时如实记录，不在提示词中伪装选模。

本文件为本 Skill 原创交接方法，不是任何图像供应商的官方接口规格。数据字段与命令见 [工作台接口](workbench.md)。

## 最终交付

分镜最终确认后执行[制作物料包规范](production-package.md)，除提示词外必须交付已用参考图包、逐镜上传清单及缺项。已有资产优先复用并去重打包，不再次生成。

## 实际上传图片的画幅检查

分镜图的单格比例、拼版整图比例、输出视频比例是三件事。三列两行的16:9画格会组成约8:3的整图；节点或提示词写16:9不会改变文件像素，也不能证明模型会接收它。

每次生成包交付或写入画布前，必须确保**最终实际上传的每个文件**有适用于本次入口的规格核验，包括宫格、长卷、裁切图和加边后的版本。文件哈希/版本未变且平台、模型、模式与用途的规格依据仍适用时，直接复用现有核验；新增、替换、适配或缺少可靠证据的文件，用Pillow、ffprobe或平台媒体元数据读取实际宽高、方向、格式和文件大小，在现有素材映射中记录路径、哈希、宽高、宽/高、目标平台/模型/模式的适用依据与检查结果。不能只读文件名、节点ratio或视频输出参数。可用命令：`ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of json IMAGE_PATH`；路径按实际环境正确引用。

参考图限制按当前入口已核实规格判断；输出视频可选比例不是参考输入限制。不知道最大宽高比时不得编造阈值，优先将自制上传拼版排入该入口已验证可用的标准画幅，并标明尚未通过新一次生成验证。普通参考不强制与输出视频同宽高比；平台支持的竖版人物等继续可用。

发现不合规，先适配上传副本：保持内容等比缩放与明确阅读顺序，使用留白排版、调整宫格布局，或在参考数量允许时导出独立画格。不得拉伸人物/建筑或裁掉重要信息；不为纯尺寸适配重新生成已采用画面。复核缩小后的细节可读性；留白与分格说明为版式，不进入视频。保留采用原图，关联上传副本来源。

替换画布图片时同步核对实际引用：更新正文标签/素材映射，移除旧图对当前生成节点的连线或活动引用，回读入口实际消费的当前参考列表；接口无法完整反映生成草稿引用或仍有尺寸报错时，再检查相应生成面板。仅新增正确图片、只改节点比例、只改提示词都不算完成。历史已提交任务的输入快照继续保留，不为更新草稿改写历史。上传成功只表示素材入库；本地尺寸检查、平台回读、用户实际生成成功分别记录，不为验证而越权点击生成。
