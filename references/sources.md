# 资料来源与验证范围

本 Skill 的制作规则、工作台与工程工具由 Cine AI Video Director 统一维护。以下资料用于核对导演术语、工具接口和模型能力；它们不替代当前项目的创作决定，也不表示对应场景已通过实际媒体验证。

- [Yale 摄影](https://filmanalysis.yale.edu/cinematography/)与[剪辑](https://filmanalysis.yale.edu/editing/)：导演术语与分析参考。
- [Blender 官方 Python API](https://docs.blender.org/api/current/)与[手册](https://docs.blender.org/manual/en/latest/)：执行时按目标版本查询。
- [Blender Lab MCP](https://www.blender.org/lab/mcp-server/)：工具实现候选，是否可用以本机真实连接为准。
- [Seedance 2.5 官方介绍](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)：白模与素材参考方向；具体平台、账号、参数和音频能力另行核对。
- [导演与动画资料索引](production-detail/research-sources.md)：教学资料、社区方法和平台指南的来源与适用范围。

需要详细工程方法时，按[制作技术索引](production-reference-map.md)读取；不依赖其他项目目录或额外下载包。范例、Schema 和检查器只能证明其覆盖的声明与数据关系，未做媒体生成的示例不称为实测效果。模型及入口能力不固化为永久上限，实际投产时核对。
