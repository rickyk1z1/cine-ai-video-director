# 按需使用Topaz Video AI超分

## 何时进入

用户确认整段或整支视频内容做好后，主Skill先主动问一次是否需要Topaz；询问本身不启动处理。只有用户选择使用或已经明确要求Topaz，才进入本执行分支。仅生成成功、下载完成或局部待剪素材采用，不触发询问。执行前说明拟处理的确切文件、参数和输出位置；用户尚未选参数时可提供以下可调整处理档：

> 先按源宽高与目标播放环境确定输出分辨率。无另定目标且输入不高于1080p时，可从2×放大、Proteus自动增强和可审阅的H.264 MP4起步；保留源帧率、时长与音轨，另存新文件，不覆盖原片。

用户已经明确要求“按默认Topaz处理”时直接执行，不再重复询问；未明确授权处理时不打开Topaz。

## 默认处理档

| 项目 | 默认值 |
|---|---|
| 输入 | 用户刚确认完成的确切整段文件 |
| 视频类型 | Progressive |
| Enhancement | 开启 |
| AI model | Proteus，Auto |
| 输出分辨率 | 按交付目标决定；无目标且源不高于1080p时可用2×，更高分辨率先核对目标，不机械放大 |
| Frame interpolation | 关闭；本流程不改变帧率 |
| 编码 | H.264，Profile High |
| 码率 | Dynamic，Quality High |
| 音频 | Copy，保留原音轨 |
| 容器 | MP4 |
| 命名 | 原文件名后加本次实际放大倍率或输出分辨率，保存在项目规定的成片目录 |

这些是可调整的起步参数，不是跨项目固定交付规格。用户指定4K、编码或输出位置时，以本次选择为准；帧率保持输入值。输入没有音轨时不得虚构“音频已保留”。

## 执行与记录

1. 先用媒体探测确认输入文件身份、宽高、帧率、时长、编码和音轨；必须是用户刚确认的整段版本，不从相似文件名猜测。
2. 在本机已有Topaz Video AI中导入该文件，从无预设编辑开始，按源规格和本次交付目标设置；确认Frame interpolation关闭，不做帧率转换。
3. 导出到项目规定目录，使用独立文件名。原片是内容母版，禁止覆盖、移动或删除；Topaz失败时原片仍保持已确认状态。
4. 记录Topaz版本、实际模型与参数、输入和输出路径、处理完成状态及可取得的耗时。界面显示加入队列、模型已加载或输出文件开始增长都不等于完成。
5. Topaz显示导出完成后再验收输出；项目有当前状态或成片说明真源时，按项目规则更新，不另建第二套清单。

## 快速复用与界面操作

这段流程属于本 Skill 的 Topaz 收口分支，不创建另一套超分 Skill。需要用 Record & Replay 捕捉用户操作时，录制结果用于修订本页的稳定控件目标与验证方法；不得把文件名、项目路径、人物内容或一次演示的临时窗口坐标写成固定业务参数。

执行前先读真实输入媒体，而不是沿用上次界面状态。记录宽高、名义帧率、时长、视频编码及音轨；同一 Topaz 工程可能仍保留旧视频和旧参数，导入后必须确认时间线内容及源帧率属于当前输入。

### 当前已验证的7.1.4界面路径

导入当前输入后，按语义控件而非固定坐标执行：

1. Adjustments → Enhancement开启；Output resolution按本次已定目标选择；Video type按源文件选择；AI model选择适用模型并记录，Proteus Auto是可用起点。不要启用Grain、Focus fix或与目标无关的修复。
2. 确认Frame interpolation关闭；若旧工程保留开启状态，关闭后回读源帧率。不进入帧率模型或重复帧补正设置。
3. Motion deblur、Grain、Focus fix及其他修复效果保持关闭；本分支只处理分辨率。
4. Codec settings：Output type=Video、Codec=H264、Profile=High、Bitrate=Dynamic、Quality level=High、Audio mode=Copy、Container=mp4、无LUT。
5. Export as选择项目成片目录，文件名使用本次实际倍率或输出分辨率；不得输出到临时工作目录后冒充最终交付。原片不覆盖。

每一步只核对本次实际选择的权威信号。按本次选择回读模型、输出尺寸、源帧率及编码/音轨；确认插帧关闭，不把上次工程参数当本次默认。已出现这些信号后不重复打开同一菜单。导出开始以Export queue出现任务和实际文件开始写入为准；队列数字、蓝色进度条和文件增长均不是完成。

如果原生界面支持稳定的语义控件，优先用Computer Use按名称/当前状态操作；Record & Replay只用来补充实际演示证据和减少重复探索，不能跳过输入身份、参数回读、导出完成及成片解码检查。

## 完成验收

- 读取输出媒体参数，确认宽高、编码与本次选定参数一致，平均帧率与源文件一致、时长与输入一致且音轨状态符合输入。
- 对视频和现有音轨执行全长解码检查；无报错后再报告文件可用。
- 抽查开头、中段和结尾，确认没有明显放大伪影、速度变化、黑帧、画幅错误或音画缺失。技术检查不替代用户对清晰度和运动效果的采用。
- 清楚区分“Topaz导出与文件验收通过”和“目标播放设备或其他真实消费者验证通过”；没有真实播放就不宣称现场验收完成。
