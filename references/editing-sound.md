# 镜头组、剪辑、连续性与声音

在切镜目的、观看节奏、时长预算或声画关系需要推敲时读取。本页设计将来怎样接镜与用声，不接管后期剪辑、配乐、混音或成片包装。声音的制作范围与执行边界只由[声音计划](sound-plan.md)维护。

## 镜头组如何成立

镜头组围绕一个明确的表达目的，构成相对完整的视听信息单元，像文章中的一句话。它应有可理解的起点、必要的发展和明确的落点，让观众看完能够理解这组交代了什么，或感受到什么变化。仅仅主题相近或发生在同一地点，不足以证明这些镜头已经组成完整表达。

完整不等于事事交代完：可以用悬念、情绪或余韵收尾，只要本组承担的表达已经完成，并有意承接后续。起点、发展和落点是表达关系，不对应固定三个镜头；一个持续镜头也能完成一组表达，不为形式补镜或拉长时长。先按表达划定镜头组，再按[生成分组方法](generation-strategy.md#从逐镜判断落到可制作的生成段落)决定独立任务或合理合并，宫格排版另按图稿阅读需要处理；生成任务的合并或拆分不改变镜头组承担的表达关系。

分镜设计时判断本组从什么状态进入、经过哪些必要信息或变化、最后落在哪里，是否能用一句话说清本组完成的表达；在已有构建思路或组说明中按需体现，不增加必填表格或确认环节。切镜可用于转移关注、揭示细节、看见反应、交代空间、省略时间或产生节奏落差；“已经过了两秒”本身不够。

问前镜留下的问题在后镜得到回答、延迟还是改变。信息相近时仍可通过表演、对照或重复产生作用；没有作用的相似切换按[信息重叠审查](continuity-review.md#构图重复须独立于空间合理性审查)调整，既不为丰富镜数保留空切，也不机械合并有效镜头。

## 连续性工具与有意偏离

| 工具 | 帮助观众追踪什么 | 当前需要确认什么 |
|---|---|---|
| 关系轴与摄影机所在侧 | 人物、运动与视线方向 | 轴来自谁或哪条行动，人物移动后是否改变 |
| 视线匹配 | 看的人与所见对象 | 对象位置、高低、朝向与实际视点 |
| 动作匹配 | 切镜后的动作持续 | 手、物件、阶段、速度及有无有意省略或重叠 |
| 屏幕方向 | 行进与出入画 | 改向是否有转身、机位运动或换场依据 |
| 空间重建 | 改变后的关系 | 是否通过可见跨轴、同框或新线索重新定向 |

跨轴、跳切、重复时间和位置变化也能服务表达，不要求所有作品使用隐形连续剪辑。有意偏离时保留想产生的体验与可见依据；不能用“艺术”掩盖无意错位。相邻机位变化没有一个万能角度阈值，正反打也不必景别相同。实际图像检查统一见[连续性审查](continuity-review.md)。

## 时间、节奏与蒙太奇

动作中切、反应前切和反应后切具有不同作用。先看等待者能形成期待，留在动作发起者身上能让画外回应影响他；不必等每个动作做完才切。省略非关键时间时保留理解所需的起因与结果，不能把必要体验一起省掉。

蒙太奇可借形状、动作、颜色、方向、声音或意义跨越时空。图形相似不保证主题成立；并置暗示因果或功能时还须符合原始信息。匹配构图服务观看联系，普通参考图不是逐幅到位的命令。

需要验证切点与对白时，按[用时间检验设计](storyboard-development.md#用时间检验设计)选择已有静帧与声音做计时预览。纸面预算、实际播放与正式录音是不同证据，预览不是所有分镜的前置步骤。

## 总时长受限时，按信息量分配节奏

先区分作品播放总长、现场讲述/采用录音、生成素材时长与可用裁切区间。保留片段先占据真实时间，剩余内容分配余量；尚无排演或录音时给有依据的估算，不停止可继续的分镜设计。

在同一播放时间线上安排对白、表演、运镜与场景变化。能并行就共用时段，连续动作被切镜承接不计两遍，只有必须分别读清的重点才顺序占时。每镜不自动附加完整“建立—动作—反应—转场”时长。全部镜头加总后回看实际观看过程，不能靠逐项累加证明作品必然很长。

镜头长短由熟悉程度、信息密度、动作难度、表演和节奏对比决定。单一细节可以短促，但小字、细微情绪变化与复杂操作需要时间；大场面可能需要欣赏，也可能因环境早已建立而快速通过。“远景长、近景短”不是通则。多中心构图还要考虑注意从一处转移到另一处所需的时间。

超出目标时，先删无作用重复、空等与绕行，再改变并行关系、入口状态或镜头组合。不要优先删承担人物关系、空间与因果的接点，也不要平均压缩所有镜头。确实不可兼容时指出哪项内容占时及可行选择，不擅自删原文或编造更短可行时长。

改时长必须同时改相应动作、摄影、观看停留、声音与首尾。原来完整抬起再放下的动作不能只把秒数减半却全数保留。同步当前分镜和受影响输入，旧任务快照不回写；分包与裁切余量按真实入口处理，镜头目标时长不自动等于一次独立生成时长。

### 内容、平台时长与裁切余量

内容时间只计算本片实际展示的观看过程。先按正常速度检查主要动作、读句与信息，再给有依据的范围和选定值。动作中切镜，前后两镜各占自己展示的那部分；同一时刻的表演、摄影和声音共用时间，不把它们的预计长度简单相加。跨镜对白沿原音轨继续，不能每换镜重新给整句长度。没有新的观看作用时，不给每镜自动加“建立一秒、反应一秒、结尾一秒”。

平台只有固定时长档位时，例如内容为13.5秒而入口只能选15秒，这1.5秒是生成余量，不是内容突然变成15秒。需要余量时记录它在整条素材或指定切点的实际位置、作用与可用区间，不能默认每镜都有一份padding，也不能摊进所有动作让表演变慢。内容确需在结尾停留供阅读时，将这段作为有叙事用途的内容计时；它与为技术裁切保留的画面不同。

下游检查同时看当前镜头合计、内容区间、生成区间和平台档位。13.5秒内容若安排在15秒素材的前13.5秒，应明确剩余尾段如何保持可裁状态，而非把最后一镜正文自动拉长。反之，必要录音或操作装不进内容窗口，应调整镜头设计或说明目标冲突，不能用参数改短、倍速播放或静默裁掉对白来伪造校准成功。

### 时长校准接口

`scripts/pacing.py`提供纯函数，不调用媒体平台、不自动保存：

- `summary(doc, shot_ids=None)`读取当前内容秒数；`content_duration_seconds`在存在未定镜头时为null，同时给出`known_duration_seconds`、`unknown_shot_ids`及`shot_count`。旧数据的0秒也作为未定，不用已知小计冒充全长。
- `apply(doc, plan)`先核验全部计划，再返回修改后的文档副本。任一项非法则不应用；不改变原文档、记录采用、阶段、确认、修订号或已提交任务。外层通过工作台同一次修订保存当前文档及计划依据。

最小计划如下，示意值不能直接当实际计时：

```json
{
  "evidence": "说明本次用户反馈、正常速度预演、语音或参考来源；暂估则明确标出",
  "source_revision": 12,
  "shots": [{
    "shot_id": "实际稳定镜头ID",
    "duration": 3.5,
    "duration_range": [3.2, 3.8],
    "basis": "动作与摄影同时开始，移除了原来重复计算的机位停稳时间",
    "changes": {"camera": "相机随主体移动，主体停下时构图同时到位。"}
  }]
}
```

`evidence`与逐镜`basis`须有内容，解释为什么这个预算成立；程序只能核验它们存在，不能替人证明依据真实。`duration_range`可选，用于保留合理区间或由已测声音决定的下限；`source_revision`可选，提供时必须对应当前读取版本。`changes`可同时修改content、framing、camera、sound、start、end、transition、reason、notes，不改镜头身份或平台参数。变化不涉构图时无需为了形式填写这些字段。

复杂重叠才补可选`beats:[{"description":"动作与运镜并行","start":0,"end":3.5}]`；允许事件重叠，不自动累计成镜头时长。单一动作不填节拍表也可校准。平台档位、裁切余量与投喂正文仍由当前生成包维护；该函数不偷偷改参数或已经提交的输入。

### 两个不同题材的纸面校准示例

下表是虚构方法示例，秒数来自明确动作安排的纸面暂估，没有录音、实拍计时或生成验证。它检验理由是否一致，不证明创意或真实运动必然正确。

| 场景与观看过程 | 原预算的问题 | 暂估与选定值 | 需要同步的设计 |
| --- | --- | --- | --- |
| 桌面收纳夹短片：车票靠近入口→滑入透明夹层→翻页→夹内车票与出行小物同框 | 四镜各给5秒，共20秒；第一镜把手部靠近与相机靠近累加，第三镜重复前镜已经开始的翻页，结果镜留了无用途的空等 | 各镜约2.25–2.75、3.75–4.25、2.75–3.25、3.75–4.25秒；当前选2.5+4+3+4=13.5秒，仍待真实操作核实 | 第一镜相机与手同时接近；滑入动作中切近景；翻页镜从已开始的动作承接；最后4秒用于认出收纳结果，不能再附一段统一padding |
| 搬家前的空屋情绪短片：取下最后一张合照→看墙面留下的浅印→关灯离开 | 原7+7+6=20秒，第一镜包括重复建立空屋和摸索拿稳；情绪停留有价值，不能一起乘0.7 | 约2.5–3.5、5.5–6.5、4.5–5.5秒；当前选3+6+5=14秒 | 开始时手已扶住相框，取下与相机拉开并行；墙面浅印保留6秒让离开感成立，第三镜只跟随离门并关灯，不另追加一段空镜 |

后一例仍有明显慢镜头；更紧凑来自改变入口状态、消除重复，并非把人物全程加速。若用户想完整保留摸索相框的犹豫，那是另一种表演意图，应重新给出更长区间，而不是把14秒当硬指标。

## 生成转场与后期转场分开

生成素材默认不做叠化。设计实际连续摄影、可理解的实体遮挡/变化，或明确真实硬切；后期需要叠化时准备可用首尾。用户明确选择生成阶段叠化时才覆盖默认，具体写法见[提示词约束](prompt-constraints.md)。不以“自然衔接”替代具体过程。

## 声音参与设计

先说明本镜需要听见什么、从哪里来、为何在此刻出现。对白、旁白、故事空间内声响、音乐和主观声音各有作用，不必每镜填满全部声部。现场有人讲话、某人无需对白或未安排音乐，都不自动等于全静音；单条完整作品、多条素材与局部返修的具体处理沿用[声音计划](sound-plan.md)，本页不另设全局禁声规则。

声音可先于画面透露下一空间，或在画面切走后延续上一空间。写清声源、进入点和离开点比仅写 J-cut/L-cut 更可执行。动作音效应跟随真实动作事件；强声后的停顿、有意静默和克制细节都可形成节奏，不自动新增音乐或环境铺底。

保护已定台词、声线、语言与采用录音，声音路径改变不能悄悄重写内容。源音频总长、实际采用区间和片内起点分别理解，以真实听检与同步效果验证，不用字符数或文件存在代替时长和口型。

## 先确定说话动作和跨载体接点

角色亲口反馈时，让脸、嘴与动作足够可辨，安排看谁、听者怎样回应、摄影机是否移动。不能擅改画外音；有运镜也不自动失去口型可读性。全景中的小人脸若无法辨嘴，就不能宣称能检验口型。

一句话跨视频、演示页或现场时，分清完整语义、画面切点与各端播放责任，按具体词句与触发衔接；换画面不等于重新起句。是否保留完整录音或逐句独立触发沿当前安排，不把所有声音一律合并，也不擅自剪原声。

改变说话时机后同步受影响的分镜、实际音频区间和输入。当前草稿、平台实际提交、播放器静音和下载音轨是不同对象；准备正确不代表旧视频已修好。结果中实际听声、看嘴与动作，不仅查看参数。
