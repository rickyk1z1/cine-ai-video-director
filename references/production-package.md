# 资产、分镜图与制作物料

当前工作台与已定决定是制作依据。先沿[工作台接口](workbench.md)读取实际保存稿、采用资产与本次范围；记录在同一数据中，由工具派生阅读稿。

## 本段物料

从分镜反查身份与阶段、服装/持物、场景/机位/昼夜、道具、准确图形以及声音。已有适用素材直接引用，只补当前镜头确实缺少的部分；基础三视图不等于所需动作图，参考、候选、文件名“最终”或修改时间也不等于采用。

先区分资产图、供人审阅的状态图和实际视频输入。它们可以复用同一文件，但职责不同；一张图只表达一个时刻。以稳定ID保存实际文件、来源、用途、采用与关联镜头，`asset_role`可为 identity/scene/prop/storyboard_frame，`grid`保留真实画格映射。实际用过的图片记录在 `actual_inputs`，依赖不替代用图清单。

## 批次范围、依赖制作与集中审阅

开始图片制作的选择由主入口统一处理；已有决定直接沿用，不在此重问。按依赖准备：回查原文与已有素材 → 列出必要缺项 → 补母图并集中采用 → 派生正式分镜图。已采用素材不重复确认；缺少某个关键母图，只影响依赖它的分支。

默认使用宿主内置生图；用户指定模型而接口无法核实选择时如实说明，不凭提示词里的模型名称宣称已经调用，也不静默改用外部收费API。编辑须提供实际原图；结构缺陷先修源图，不反复沿失真的末代图累积修改。独立身份、场景和道具分别分配职责，没有人物的环境图不默认附人物三视图。

同一资产内部可用候选作临时工作基准，但不能因此填采用依据或混入正式采用图。新图先检查明确的畸形、身份、空间、动作状态与视觉重点，再交用户集中审阅。相同问题连续定点修复无改善时回查输入与实现方式，不无限重抽；不把失败图称为可用。

正式逐镜图依据已选且适用的资产。若用户明确选择其他输入方式，按[输入适配](input-adaptation.md)处理，不为合法文字直投或外部视频返修制造图片。一次状态图已足够表达镜头时直接复用，不要求每镜固定起中尾三张。

## 当前图序与局部修改

工作台按当前镜头顺序展示候选与采用图，每图独立编号，原图可查；同镜多状态按明确时序保存。整板与单图依画幅、连续性和清晰度选择，不凑格。实际上传前检查[图片交接](image-handoff.md)规定的尺寸与职责。

用户在图稿阶段要求改逻辑、补镜或新增状态，使用 `revise` 同步文字与图像记录，保留阶段与既有许可。用户对图像的采用与同范围修改授权仍是两回事，工具不把新生成文件自动标为采用。未受影响的采用内容保留，原图需要复核时仍可查看，明确当前用途而不删除历史。

整批图确认后，助手只做一次[整段图序预演与审查](sequence-review.md)，并在工作台给出生成建议。用户按建议人工调整后不重复审查；仅更新相关图稿、生成建议、引用和投喂输入，保持原审查已完成的事实。

## 集中交接

用户应能从一份当前阅读入口找到镜头、实际采用文件、下一步和真正缺项；平台生成视频的归属按[媒体目录](media-layout.md)，不与分镜预演混放。素材原位复用；准备手动或自动包时，只复制真实投喂需要的文件到新交付目录并核验字节，保留来源映射，不另建平行资料库。

生成建议是随镜头更新的工作信息：设计初稿给初步方式，图稿审查时给具体模式、分组、输入与效果/成本取舍。实际输入按导演目标选择，不把所有审阅图都上传；详细字段见[工作台](workbench.md#整段预演一次审查与活的生成建议)，执行见[视频生产](video-production.md)。

`prepare`与`package --output`输出提示词、参数与实际附件映射、manifest。输入校验与文件复制不代替实际平台消费、媒体解码、声画检查或用户采用。旧任务始终指向它实际使用的版本，新的反馈不会追溯改写历史。

母图派生及跨视角一致性需要时读[图像依赖方法](production-detail/reference-image-driven-assets.md)，人物资产读[人物图方法](production-detail/character-image-assets.md)，实际3D资产读[资产管理](production-detail/asset-library.md)。详细清单是助手解决具体问题的方法，不成为每轮都要用户填完的表格。

## 绘图范围与实际投喂

按已选输入方式反查缺口，不默认每镜起中尾三张。简单画面直接做；复杂空间、接触、遮挡或连续路径先以低成本粗构图、标注或必要预演解决结构，再精修。内部粗稿不增加用户确认；关键观看意图确需改变才讨论取舍。粗构图、状态图、动作参考和三维预演是备选控制手段，不默认全部叠加。先选能够解决当前缺口的最少一种；只有它仍缺少独立、必要的信息时才补另一种，并说明补充价值。不能仅因涉及递接或复杂动作就宣称必须三张状态图再加演示视频。

审阅图帮助用户理解方案，实际生成参考承担模型控制，两者可复用同一文件但不自动整批上传。逐项说明引用的属性、允许变化的部分及冲突；身份图、表情图和空间图可按需要分别准备，不强制建立齐全素材库。局部改图优先编辑采用原图；反复漂移回到稳定母图和空间依据，不沿错误末代图无限修改。
