# 人物走位与相机路线共同设计（规则 3.2.6）

> 详细技术参考，按[制作技术索引](../production-reference-map.md)选择本次需要的部分。当前分镜、已有决定、采用声音和所选路线优先；技术参数应在实际工具与版本中核对。


本参考用于已选中的结构预演：先验证人物根位移、屏幕方向、相对距离、遮挡和相机路径。只有 `previs_profile.character_motion_scope` 明确选择 `articulated_performance` 时，才执行下文的步态、脚底、全身IK 和身体曲线验收；简化接触手部按 [局部手部规范](contact-hand-ik.md) 执行，不触发完整验收；根位移代理不得被称为已验证跑动。

本页检查用于制作、修改或用户明确要求的专项复核。用户认可当前白模与动画后，按 [用户确认与视频提示词交付](../video-production.md) 直接交付，不因技术项目尚未验证重新检查。详细肢体范围必须有用户明确要求。

用于跑动、追逐、对话移动、打斗换位、跟拍和长镜头。先读对应导演意图；身体动作另见 [animation-and-performance.md](animation-and-performance.md)。依据为 [来源索引](research-sources.md) 的 D01–D03、D07、B01–B07、P01；下面路线表达、数值方法与验证是本 Skill 的工程应用，须在场景中实测。

## 空间先成为可行动的地图

Blender 世界坐标：米、Z向上、角色默认+Y。单独定义 screen_left/right、镜头 local axes 与世界 axes；提示词资料里的“Z远近、Y高低、X方位”不是 Blender 世界坐标。

俯视图/数据记录：可走区域、地面高度、障碍包围体、门洞、遮挡面、出入口、起点、经过点、停止/接触点、人物朝向、相机通道和本段动作轴。垂直动作另记录高度；只画平面线不足以验证楼梯、跳跃或俯冲。

先给演员排路，再给相机选观察位置，同时允许两者为画面共同迭代。人物的移动应改变距离、可见性、控制权或接触条件；不要为填镜头让每个人无目的绕圈。固定人物也可通过前后景、走入/走出遮挡和另一人物移动改变关系。[D03]

对每条路径记录 `path_id, owner_id, coordinate_space, waypoints, time_marks, stop/turn/contact_events, facing_policy`。空间曲线和时间曲线分开；曲线经过目的地不意味着在正确帧到达。

## 位移来源与可编辑路线

地面行进默认使用最终 `.blend` 中保留的可编辑 Curve。记录 `curve_id`、对象名、控制点、方向、时间映射、朝向策略和停步/转身事件；空间和时间曲线分开，避免非均匀缩放。路径进度、旋转和局部姿态各有明确职责。

| motion_owner | 使用情况 | 制作约束 |
|---|---|---|
| `static` | 没有整体位移 | 不创建无用 Curve；仍可有明确整体旋转 |
| `curve_follow_path` | 行走、跑动等自主空间移动（默认） | root 仅一条有效 Follow Path，目标为声明 Curve；无 root Location 曲线/驱动和父级重复平移 |
| `parent` | 搭乘车辆、升降台或随载体移动 | 声明实际 parent/载体和局部锚点；该范围由父级提供位移，root 不同时带 Follow Path 或 Location 动画 |
| 其他明确来源 | 局部事件、约束交接等特殊需求 | 记录对象、时段、自由度与原因；通用快速脚本未支持时记未验证，不冒充已支持 |

任一时段只让一个指定来源负责同一位移自由度。角色下车、道具交接或跨来源切换时声明前后来源、交接帧和世界变换保持方式；不以双重位移补偿错误。道具的开合/旋转可由自身轴和局部旋转曲线执行，不强加角色路径合同。

Follow Path 显式记录 `offset_factor` 或实际时间映射、forward/up 轴与 `use_curve_follow`。后退、侧移和看向别处时，朝向与行进分离；方向可独立控制，不必重写位置来源。可视辅助路径与方向标记留在工程，默认不进参考视频。

制作/修改时只对本批控制来源和交接做必要检查。Fast 的静态、Curve 和纯 parent 检查范围见 [快速验证](fast-validation.md)；它不能证明所有父级旋转、骨骼 root motion、约束叠加和控制切换都正确。未执行项保持未验证，用户认可后不追加检查。

## 跑动路线与时间

1. 以角色尺度、地形、动作片段和情绪选择速度。先算路程/可用时间，识别瞬移或离谱冲刺；没有统一适用于所有人的“电影跑速”。
2. 用弧长 s(t) 控制沿路径的位置；给起跑、制动、转弯和接触预留时间。不要让每个途经控制点自动 Ease In/Out，从而不停减速再起步。
3. 拐角采用可走通的圆滑过渡，或以减速、整体转向、再加速表达急转；支撑脚蹬转仅在详细肢体模式制作。转弯可参考横向加速度 v²/r，不能将路线合理性等同真实身体动画。
4. 人物朝向随动作而定：常规向前跑可参考路径切线，侧移/后退/观察身后必须让朝向与速度可分离。起点静止或速度接近0时沿用明确朝向，不用零向量建朝向。
5. 两人追逐同时画各自 s(t)、距离随时间变化和遮挡窗口。不能通过每次切镜重置位置来维持追赶；接触前用相对距离与闭合速度估算是否来得及。

根据Blender5.2源码的既有核验记录：Follow Path已按采样路径累计弧长求位置，静态、尺度合适的路径使用线性factor通常能近似等弧长推进；不能把它描述成原始Bezier参数必然忽快忽慢。曲线非均匀对象缩放、变形、移动、owner偏移及后续约束仍可能改变最终世界速度。先采样最终世界位置验收，需要时才建立世界弧长查找表与时间映射，或烘焙后复测。该版本源码只使用第一条spline，多段路线须显式连接/管理。[B01,B07]

## 相机路线与视点

相机使用自己的路径，禁止将相机刚性绑定到人物root当通用跟拍。让运动目标、画面构图、摄影机可走空间共同决定轨迹。

| 方式 | 能观察到什么 | 路线注意 |
|---|---|---|
| 侧向平行跟拍 | 步态、速度、两人距离与空间参照 | 保持选定轴侧，留运动方向空间；转弯时不要偏移线穿过弯内障碍 |
| 前方退拍 | 表情、决定、前后人物关系 | 相机走的是独立可通行线路，保持人物身后信息可读 |
| 后方追随 | 目标方向、路线、未知空间 | 关注前方揭示与人物遮挡，不把背影永远锁死画面中心 |
| 斜向三分之四跟拍 | 身体体积、行进方向与部分表情 | 平衡侧向位移与画面深度，避免轴侧在弯道中无意改变 |
| 固定机位让人物经过 | 速度参照、距离、克制观察 | 留进入与离开的时间；可接第二固定机位或等人物改变画面关系 |
| 从跟随转为揭示/停留 | 注意力从人物移向目标或留下的反应 | 明确脱离与接管时刻，不能用突然切换父级制造跳变 |

初始构图可由角色参考点 P(t)、平面前向 T(t)、侧向 N(t)、高度 Z 建立候选机位 C(t)=P(t)+aT(t)+bN(t)+hZ。这里只生成候选位置：弯道、停止、障碍和叙事脱离需修正；最终机位有独立时间与曲线。N须采用稳定连续方向，避免每帧翻转。

look target 使用胸腔、头部、两人加权中心或明确的空间锚点；按叙事变更。前视量 v(t)·τ 可辅助看向行进方向，τ是可调设计值，需要限幅及转弯检查。眼睛向哪看、相机向哪看、焦点在哪是三个独立问题。

## Blender Rig 与运动曲线

### 摄影机圆滑转弯的默认实现

镜内连续运动默认像真人持机/推轨：路线转角用Bezier、连续样条或有明确半径的圆弧过渡，连接处方向连续，速度按情绪与行走空间衔接。转弯半径由通道、障碍、主体距离和速度选择，不固定套某个米数；空间窄时提前减速并逐渐转向，不能用直角折线或瞬间换机位补救。

空间路线与时间插值是两件事：`offset_factor`或烘焙进度用Linear可表示匀速时间推进，但空间曲线仍须圆滑。多段直线加密关键帧不会消除直角，所有关键帧改成Bezier也不证明速度和转向自然。普通经过点不自动停住再启动；起步、制动和有意停留才安排相应缓动。

位置圆滑后还要处理视线：look target沿连续轨迹移动，或对朝向按时间连续插值；揭示新方向时把平移、摇摄/俯仰和需要的迟跟分摊在实际时间内，避免一秒内从近目标跳到远目标而急转。不能靠Damped Track名称假定已有时间阻尼。合并镜头时同时接通位置、基础朝向、焦段和手持相位，不只删除切镜Marker。

路径、朝向、速度和起止构图须联合满足 [内容表达时间](directing-story-and-editing.md#4-节奏层级整场节奏与切点)。主体转移时明确注意力何时离开原对象、途中需要看见什么、下一对象何时可读及随后停留的用途。弧线不为展示曲率而绕远；加快转场仍需自然起止与连续观看方向，不能突然换目标或到位即切走。需要迅速接话时可短促移动并充分停留，需要持续观察时可以边移动边表达，不统一规定速度、弧度或稳定时长。制作中的局部预览关注这些屏幕效果，曲线存在或插值设置正确不证明观感合格。

制作中就地查看本次转角附近的少量实际画面，并按需有界采样最终基础速度、角速度和连接两侧变化；关注门框、弯内障碍、人物后脑过近和揭示节拍。改路线只影响摄影机时，不通过挪动人物或丢失事件来掩盖问题。所谓“丝滑”是基础运动没有无意顿挫，不要求消除已确认的恐惧手持、冲击或叙事硬切。

用户明确采用机械式折转、甩镜或故意顿挫时，按该镜头例外执行并记录动机；正常叙事切镜可以保留，不把不同机位硬连成一条穿墙的路线。选择合并镜头先有可行的连续通行与取景。人工认可后不再重跑上述局部检查。

按需要分离 `RIG_CAM_PATH`（位置/基础朝向）、构图修正、可选风格层、Camera；目标和焦点分别为可查询 Empty。层数按任务简化；避免两层同时控制同一个自由度。

- Blender 相机局部通常朝 -Z、局部Y为上。Track To 的 track/up 轴须按实际对象检查；目标方向与up平行时检查翻滚/奇异情况。Damped Track 的“Damped”指旋转求解方式，并无自动时间延迟。[B02,B03]
- 若要时间滞后/阻尼，明确实现时间常数、预滚和初态。离线预演优先按顺序采样后烘焙平滑目标/旋转，使跳帧、逆向拖动、重复渲染确定。不要依靠未缓存的有状态 frame handler，使相同帧因访问顺序而不同。
- 平移、摇移/俯仰、滚转、焦距、焦点分别排曲线。恒速段用合适线性或速度控制，启动/制动有动机；Bezier不自动等于优美，自动手柄可能过冲。[B04]
- 四元数可减少Euler绕圈问题，但仍须处理相邻四元数符号/最短路径及受控roll；不能把转换旋转模式称为已经消除翻转。
- 约束交接/父级交接要保持世界变换，校准 influence，并抽查交接帧两侧。相机不必复制人物每次落脚的上下波动。
- 手持与冲击只是可选风格层；固定seed、连贯频谱、幅度与衰减。慢镜、手持、环绕、变焦皆按意图选择，不固定要求或禁止。

透视主要由机位及其到主体的相对距离决定；焦距与传感器尺寸决定视场角。固定机位换焦段不会单独改变前后比例；保持主体大小时使用长焦并后退，才形成常见空间压缩观感。景深还依赖光圈、对焦距离、焦距与成像规格；不要把85mm等同浅景深或紧张。默认36mm传感器只作为声明过的起点。[B06]

## 联合验证

制作或修改时，按所遇问题在受影响范围选择检查，必要时关闭风格噪声和重度景深；路线图或首尾两帧只能证明其覆盖范围，不默认扩展为全程测量：

- 镜内主体位置/大小/留白是否符合意图，门洞、攻击线路、逃跑路口是否在应揭示的时刻可读？有意出画登记时段。
- 相机与障碍的代理体做扫掠/足够密集的空间采样，计入近裁切面和相机体积余量；单点不相交不足以证明快速运动不穿墙。
- 在受影响镜头内部有界采样速度、角速度或屏幕运动；仅为定位高速/近障碍问题补必要帧或子帧。完整逐帧测量仅在用户明确要求时执行。指标阈值随风格、FPS 和画幅调整，硬切边界分段。
- 行动轴改变时更新轴线，并用可读转弯、机位移动或重新交代镜头让观众跟上。仅写intentional_jump_axis不能替代审片说明。
- 跟拍是否把原本固定的支撑脚显示为移动？世界检测把脚部实际接触点变换到支撑物局部坐标，与接触锚点比较，此时不再扣相机运动。屏幕检测在每帧用同一相机分别投影脚接触点与对应支撑锚点，再检查残差随时间的变化；不能统一减去一个“相机像素位移”，不同深度的投影位移并不相同。
- 相同源帧正向、逆向、跳帧求值，抽查相机/目标/角色世界状态一致；记录误差和限制。

数据报告可标可见性/碰撞/速度的采样范围。没有执行对应检查时标 planned 或 unverified；字段齐全不代表轨迹已经可用。

当前修改涉及绕前、越肩或转向另一对象时，同时检查基础路线、时间映射和看向目标的变化；曲线平滑不代表最终视线平滑。事件驱动的目标切换须有连续过渡和足够读取时间，在该段有限预览中确认没有顿挫。速度/角速度只作为定位工具，阈值依意图设定，不把单片测量值当通用标准。

其他角色的主动性及倒地扫过范围按 [交互因果与状态](interaction-choreography.md) 联合安排。路线存在不能证明观众看见逼近；检视相关角色与主角的相对距离、遮挡和实际行动。
