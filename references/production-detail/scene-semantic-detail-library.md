# 通用场景语义细节库

> 详细技术参考，按[制作技术索引](../production-reference-map.md)选择本次需要的部分。当前分镜、已有决定、采用声音和所选路线优先；技术参数应在实际工具与版本中核对。


场景细节的目标是帮助观众和视频模型识别“这里是什么、人物如何使用它、空间尺度如何”，不是堆随机装饰。

## 提炼方法

为每个空间区域从以下五类中选择少量确有用途、信息清楚的元素：

1. **功能物件**：这个空间完成什么功能。
2. **尺度参照**：门、桌、椅、车辆、栏杆、灯具、柱子等能帮助判断大小的物体。
3. **路径和边界**：入口、出口、通道、台阶、护栏、隔断和地面标线。
4. **动作道具**：角色会拿、推、坐、打开、放下、躲避或触碰的物件。
5. **环境信号**：招牌、屏幕、货架、窗户、植物、设备、警示牌等能定义场所的元素。

优先选择会改变识别、动作因果、遮挡或空间尺度的对象。不要为了“看起来丰富”随机填满场景。

## 按场景类型的常用元素

| 场景 | 可优先考虑的语义元素 |
|---|---|
| 城市街道 | 路缘、车道线、交通灯、路牌、店铺门面、公交站、垃圾桶、路障 |
| 住宅/公寓 | 门厅、门牌、楼梯、扶手、信箱、沙发、餐桌、窗帘、灯具 |
| 办公空间 | 前台、工位、会议桌、显示器、文件柜、玻璃隔断、门禁、消防标识 |
| 商业空间 | 门廊、收银台、展示柜、货架、导视牌、排队栏杆、灯箱、休息区 |
| 餐厅/酒吧 | 吧台、桌椅、菜单板、餐具、托盘、厨房窗口、酒架、服务通道 |
| 医疗空间 | 接待台、病床、帘轨、推车、门牌、消毒台、候诊椅、警示标志 |
| 工厂/仓库 | 货架、托盘、叉车、管道、护栏、工位、警示线、装卸门 |
| 学校/公共机构 | 走廊、公告栏、储物柜、座椅、讲台、指示牌、门禁、饮水机 |
| 交通空间 | 站台边界、闸机、检票机、座椅、时刻屏、行李、扶梯、标线 |
| 自然环境 | 主体树干、岩石、地形高差、道路、倒木、水面、灌木簇、方向性地标 |
| 动作/打斗空间 | 掩体、可破坏物、障碍、武器/道具、落差、狭窄通道、可利用的门窗 |
| 公共活动空间 | 导视牌、门禁、接待台、重复设备区、活动台面、休息区、服务通道 |

这些例子是候选库，不是固定清单。实际选择必须服从剧本、镜头、预算和用户资产库。

## 低成本实现

- 重复元素优先共享网格、链接复制、集合实例或 Geometry Nodes。
- 远景只保留轮廓、颜色块和尺度关系。
- 前景动作道具保留接触面、开合部件和抓取点。
- 结构道具使用低面数盒体/柱体加少量 Bevel；不为了细节默认制作高模、贴图或复杂模拟。
- 任何新增元素都要登记用途、所属区域、是否被镜头看到、是否参与碰撞，以及 LOD 等级。

## 验收

每个镜头都要回答：

- 观众能否凭这些元素识别空间功能？
- 元素是否支持人物动作和镜头构图？
- 是否产生不必要的遮挡或穿模？
- 是否有重复资产可以实例化？
- 元素是否会被视频模型误认为必须复制的最终外观？
