# 圆柱球头的尺寸与弯曲标准（3.1）

> 详细技术参考，按[制作技术索引](../production-reference-map.md)选择本次需要的部分。当前分镜、已有决定、采用声音和所选路线优先；技术参数应在实际工具与版本中核对。


适用于新建的默认人物代理。统一的是造型家族、参数含义和控制方式，不是所有角色使用同一尺寸。这些比例是低复杂度预演的美术起点，不是人体测量定律；真人外观按人物资产和剧本生成。已有认可项目不因升级自动重建。

## 参数先明确，再建模

总高`H`为站立休息姿态下支撑面到头顶的高度，单位米。优先使用角色设定/可靠参照中的身高；没有精确值时按年龄、物种与体型作制作估计，标记`height_source: production_estimate`，不为每个尺寸新增用户问卷或把估计写成既定人物事实。

| 参数 | 定义/计算 | 默认起点与可调整范围 |
|---|---|---|
| `total_height_m` | H，站立总高 | 来自角色设定；不按同一成人尺寸套小孩/异形 |
| `head_diameter_m` | D = H × 头径比例 | 成人起点0.20H，儿童0.25H；按设定调整，不自动夸张成大头娃娃 |
| `body_diameter_m` | W = H × 体宽比例；半径W/2 | 成人起点0.24H，儿童0.26H；胖瘦或非人形按轮廓调整 |
| `body_length_m` | L = H − D，圆柱底到顶 | 不把整个人的H误当圆柱长，导致另加球头后过高 |
| `head_center_z_m` | L + D/2 | 圆柱与球头相切，不增加颈部；没有默认漂浮间隙 |
| `root_origin` | 支撑面上、圆柱底部中心 | 根节点负责路线与整体朝向；+Y为角色前方、Z向上 |

例如成人H=1.75m时，圆柱长1.40m、直径0.42m，球头直径0.35m；儿童H=1.15m时，圆柱长0.8625m、直径0.299m，球头直径0.2875m。它们只演示同一计算方式，不是强制演员尺寸。异形可采用不同头径与体宽比例、总高与自然静止朝向，本模板仍保持一个可弯圆柱加一个球体；其他代理造型另按镜头与用户选择设计。

在人物/SceneSpec记录中保存`character_id`、参数来源、H/W/D/L、头中心、比例、前向、几何分段、rig名与版本。后续章节按同一ID复用这些数值；换服装不重算体型，成长/变身有剧情依据时才建立新状态版本。不能在每次续作时重新凭感觉选尺寸。

可用纯离线助手计算统一数据，不启动Blender：

```text
python scripts/previs/derive_proxy_dimensions.py --height 1.75 --preset adult --height-source production_estimate
python scripts/previs/derive_proxy_dimensions.py --height 1.15 --preset child
python scripts/previs/derive_proxy_dimensions.py --height 2.4 --preset custom --head-ratio 0.16 --body-ratio 0.28
```

工具只输出基础圆柱/球头与4骨骼的参数JSON；两个可见网格的计数不含 [可选手部附件](contact-hand-ik.md)。它不创建模型、不保证姿态或镜头效果。自定义预设需要明确比例；数据写入项目而非技能目录。

## 默认四骨骼弯曲，不是详细人体绑定

选择本圆柱球头模板时，绑定一条4骨骼链，沿圆柱长度从下向上贯穿：`Lower`、`Upper`、`TorsoLower`、`TorsoUpper`。默认关节高度为L的`0, 0.29, 0.58, 0.79, 1.00`，可按非人角色自然形态调整并记录。这些是控制同一个体块的内部弯曲段，不能据名称添加两条腿、胳膊或颈部。

- 默认圆柱16个周向分段、40个高度间隔，共41圈；球头用16周向、8纵向的低面球即可。曲弯处要有连续环线，不能拿只有上下两圈的圆柱硬折。按镜头可读性调整分段，不默认细分曲面或每帧重建网格。
- 相邻骨段的权重平滑跨越多圈，推荐单侧过渡宽度约0.07L且不超过相邻最短骨段的40%；避免一圈全部权重突变形成铰链硬折。按需要分摊曲率、保留体积，局部修正明显塌陷或自交。
- 球头随最上部躯干骨段变换，保持休息位置偏移；不另加默认头部表演轨。道具锚点随实际所属躯干区域移动，不能在身体弯曲后留在原空中位置。
- 根节点路径/整体朝向、局部骨骼姿态、支撑高度补偿各有明确控制来源；骨架不再叠加第二套水平行进。骨段长度保持稳定，禁止用缩短整根圆柱或向地板下压来冒充坐下。
- 静态建模阶段建立并绑定休息姿态，不写动作关键帧。静态结果认可后，动画阶段按剧情启用弯曲。已选择本模板的常规绑定不另开审批；镜头需要的简化接触手部按 [手部IK附件](contact-hand-ik.md) 执行，无需改选完整人体；详细四肢/步态/全身IK仍需明确改选策略。
- 有独立姿态的角色使用独立控制；静态或同姿态远景群众可实例化含rig的模板或复用姿态缓存，避免逐人叠加无意义动作。降低的是重复计算，不把主要角色退回不能弯曲的刚性圆柱。

## 大动作与支撑面

| 姿态变化 | 默认预演表达 |
|---|---|
| 坐到椅子上/蹲下 | 下段与上段形成腿部总体折弯，上身随重心下降；分别明确地面和座面的支撑高度 |
| 瘫坐地面 | 站立→膝髋区域弯曲→重心下降→臀部区域落地→姿态保持；同一圆柱连续变形 |
| 躺下 | 整体方向由直立转向支撑面，配合骨段弯曲与身体/球头的支撑余量，不让半截模型进入地板 |
| 地面起身 | 先卷起上身，再收拢下段、抬升重心并伸展至站立；可有停顿，不瞬间切回站姿 |

以当前地面、座椅或坡面的实际高度/方向作支撑，不把全世界z=0当成唯一地面。制作中针对这些变形段看变形后的圆柱与球头边界、支撑关系和相机可见范围，保留小的数值余量；不能只查未变形包围盒或只看root高度。抽样是局部证据，不声称所有帧无碰撞。没有脚网格就不做详细支撑脚/脚滑审计。

大动作足够清楚即交用户查看，真人手部支撑、精细膝踝协调、步态、表情与喘息继续写进成片提示词。用户认可后不追加姿态复核。
