# 随镜头更新的生成方式建议

生成建议与镜头设计一起维护，帮助用户兼顾表达效果和可控成本。它是专业判断，不是提前锁死工具，也不是每次修改都重做一次审批。

- **设计初稿：** 顺带说明适合怎样生成、哪些镜头可同组、哪些难点可能需要运动或空间参考。平台未定时给控制思路，不虚构具体模式、费用或参数；不要为了查遍平台而拖延创意设计。
- **图稿采用并完成一次整段审查：** 在工作台同时展示审查结论及具体生成方案。按当前真实能力落实每镜/组的模式、必要输入、分组理由、预演范围、效果风险与成本，再推荐直接平台或先 Blender 预演的路线。
- **用户人工调整之后：** 不再次进入整段或局部语义审查。按用户方案更新受影响镜头的建议、素材和投喂输入，未变建议及已选路线沿用。只有实际文件、规格或能力不兼容才提示具体缺口，不要求用户重新认可自己的方案。

建议写在同一 `generation_recommendation` 记录，工作台的镜头卡显示初步方式，图稿页汇总方案与两条路线。字段见[工作台接口](workbench.md#整段预演一次审查与活的生成建议)。替换旧建议时更新同一ID或明确 supersedes，不把每轮建议堆成互相冲突的当前方案。

## 从每镜需要控制什么开始

先判断本镜最难保住的是身份、空间、起止状态、连续路径、表演、精确交互还是信息揭示；再选择足够胜任的最简单方式。普通全能参考只是选项之一。

| 控制需要 | 值得比较的方式 | 必须说明的限制 |
| --- | --- | --- |
| 主要是创意动态，画面无需精确定型 | 文生视频，审阅图可以不上传 | 不能保证具体人物或构图，必要事实要在文字中自足。 |
| 已定一幅画面作为真实起点 | 原生首帧图生 | 末态与整段路径未被锁定，不能仅靠“同图”宣称连续。 |
| 起止状态确实都需要固定 | 真实首尾帧入口 | 核实能力、时间可达性与两端几何；不要给普通参考套严格控制。 |
| 人物、道具、空间分别来自不同图片 | 多参考/全能参考 | 每份图有独立职责，不能把整组审阅状态图变成逐图落点。 |
| 动作或复杂摄影路径需要具体依据 | 运动参考视频、真实导演控制、必要预演 | 工具名称不证明实际可控制；参考只约束其支持的维度。 |
| 同空间多机位、路线、遮挡、递接 | 共用场景预演后生成 | 只做必要空间与动作，代理外观不成为正式人物或材质。 |
| 成片中只有某一镜失效 | 实际可用局部编辑/重拍或独立补镜 | 核对真实切点、两端和计费范围，长镜头不能硬拆。 |

深度图表达空间深浅与结构，不等于完整人体运动。姿态、轨迹、深度及图像身份是不同控制信号。模型和入口确有能力才用，不能把一个平台支持的参数套给另一个。

## 从逐镜判断落到可制作的生成段落

默认按“独立作品范围 → 镜头组 → 生成分组 → 声音计划”推进。用户已明确要求一次生成、逐组生成或指定组合时，优先沿用；只有真实能力、范围或费用冲突才指出具体问题。未指定生成分组时，助手根据下述标准给出一个有理由的主方案，在已有制作授权内据此准备，不额外增加分组确认。实际提交仍沿已确定的操作分工。

先确定哪些内容共同组成一部独立使用或交付的作品。按[镜头组定义](editing-sound.md#镜头组如何成立)划分完整表达单元，再以各镜头组作为生成规划的起点；镜头组本身不必等于一个生成任务，也不能为凑单次生成而改写表达组界。

- 组内镜头能用兼容的输入和控制方式实现时，优先在一次生成中完成，不机械逐镜拆任务。
- 跨组内容短、衔接紧密，且共用输入/控制方式确有利于连续性或成本时，可以合并生成，简述合并理由。仅仅同属一个作品、同一场景或平台时长装得下，不足以决定合并。
- 不同组承担独立的信息发展、场景或动态控制差异较大，或分别调整能减少重做时，优先分别生成。把接点、共用素材、声音和组间状态交代清楚，不必等到平台超时才考虑拆分。
- 单组因真实时长或控制限制需要分段时，保留该组表达与跨段接点；一次连续镜头无法保证接续时，说明限制和可行方案，不冒称拆后仍然无缝。

在现有生成建议中列出每个任务覆盖的组/镜头、预计内容时长与简短理由，使整部作品的任务范围无遗漏、无无意重复；不另建分组审批表。一次任务实际只使用入口支持的模式、模型和输入组织，不能假装每镜都能切一套互不兼容的模式。分组确定后，再按[声音计划](sound-plan.md)判断同一作品总共需要几条生成素材；不能用一次请求、当前节点或返回文件数重新定义作品范围。

比较成本时，先说可观察的准备量、生成条数和总秒数，再用真实入口可得价格估算；没有可靠价格写未知。不要用虚构成功率、固定折扣或“越便宜越好”取代表达判断。同一难点持续失败要回查设计与输入，不能只靠多次生成摊薄问题。

同一作品只有部分镜头需要预演时，可局部制作，共用空间和已有资产。所选平台确实能同时消费这些输入时，一个生成包可混合预演与图文依据；否则说明实际拆分。声音范围仍按这个独立作品真正要生成的素材条数，不按预演辅助文件或重试数判断。

生成建议提出推荐，只有用户的实际选择才成为[投产路线决定](video-production.md#本批投产路径选择门)。同一范围已有选择直接执行；输入或成本实质超出原授权时只处理新增部分。
