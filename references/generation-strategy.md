# 随镜头更新的生成方式建议

生成建议与镜头设计一起维护，帮助用户兼顾表达效果和可控成本。它是专业判断，不是提前锁死工具，也不是每次修改都重做一次审批。

- **新片段设计：** 必须评估模型＋平台入口＋输入方式＋生成分组＋必要素材，与文字分镜和拍法一起给主推荐。当前优先围绕 H3、即梦／Seedance、可灵，这是可覆盖偏好，不是永久名单；平台按画布＋Agent协作、专项功能丰富两类能力比较，可重叠。具体版本与入口有依据才推荐，缺口如实说明。按[在线方法](online-methods.md)完成资料匹配，不为查遍全部模型拖延设计。
- **图稿采用并完成一次整段审查：** 在工作台同时展示审查结论及具体生成方案。按当前真实能力落实每镜/组的模式、必要输入、分组理由、预演范围、效果风险与成本，沿用已有选择并更新受影响输入，不把到此阶段重新选路线设为必经。
- **用户人工调整之后：** 不再次进入整段或局部语义审查。按用户方案更新受影响镜头的建议、素材和投喂输入，未变建议及已选路线沿用。只有实际文件、规格或能力不兼容才提示具体缺口，不要求用户重新认可自己的方案。

建议写在同一 `generation_recommendation` 记录，工作台的镜头卡显示初步方式，文字与图稿页展示同一当前方案，默认一个主推荐，仅有实质取舍时再给备选，不为凑数给两个选项。不同独立范围分别记录建议；同一连续镜头组优先保持模型、身份、空间和声音一致。字段见[工作台接口](workbench.md#整段预演一次审查与活的生成建议)。替换旧建议时更新同一ID或明确 supersedes，不把每轮建议堆成互相冲突的当前方案。

## 先确认能做，再判断为什么优先选它

新主推荐不能只列“支持首尾帧”“时长足够”等功能。先排除不满足本段必须条件的组合，再比较剩余候选为何适合当前镜头。通常挑出最重要的两三个要求说明取舍，不设固定权重、总分或排行榜。

### 必须满足的条件

核对内容时长及实际入口的单次上限、多镜头组织和拆分影响、所需输入与控制（首帧、首尾帧、多参考、动作参考、视频编辑等）、画幅分辨率、声音与口型，以及平台入口和账户实际可用性。模型版本与平台开放能力分开：同名模型在两个平台上不一定有相同控制。已有有效核验直接复用，只有变化或具体缺口才查证。

### 可行候选之间的取舍

- **本段主要难点与表现倾向。** 人物表演、动作、产品动态演示、动态图形、文字、空间运镜可能需要不同取舍。模型特性判断须限定到具体版本、入口、任务和资料时效；用户印象用于定位要查什么，不直接变成永久标签。
- **画面要求与失败风险。** 按本段需要比较细节、材质、光影、运动流畅与可信度、身份稳定、要求遵循，以及失败后能否局部修补。官方列出某功能，只能证明可能适用，不能证明成片优于另一模型。
- **整体制作成本。** 性价比指获得可采用素材的总成本，包括准备素材、生成费用、拆段、重试与修补。区分可观察的准备量、当前真实价格和已有失败记录；没有记录就写未知，不编造成功率、预计重试次数或精确总价。
- **前后连续性与现有输入。** 与已采用镜头的角色、空间、动作和声音衔接，可能比某项单镜优势更重要。充分利用已有素材和当前可用入口，不因新型号出现就更换整段路线。

### 依据能证明到哪里

沿现有 `method_evidence` 区分官方能力资料、条件相近的案例、实际检查过的生成结果；用户经验另标为待核验线索。每项说明对应的版本/入口、日期、借用内容和限制。案例的参考素材、时长、题材或版本不同，要说明可比性；没有看过真实结果，不写成实测结论。

“支持相同模式”和“有一条好案例”都不足以证明跨模型优势。证据不足以区分时，明确两者均可，按已有素材、可用入口和可核对成本作**暂定推荐**。这仍是可执行的主方案，不因为没有对比测试就阻塞普通制作。只有重要难点值得且现有证据不足时，才建议小范围对比，并说明要验证的差异；保留既有生成权限，不把建议变成自动试生成。

在新完整推荐的 `selection_basis` 中简短写出本段重点、与备选的实质区别、整体成本和未确定项，现有 `options[].reason` 说明具体模型与入口为何匹配，`method_evidence` 保存依据范围。没有必要的备选时说明为什么只保留这个可行组合，不凑候选。工作台显示“推荐／暂定推荐／用户指定”，字段与示例见[工作台接口](workbench.md#整段预演一次审查与活的生成建议)。

旧建议和已有选择继续有效，普通续做不补填一整批历史记录；本段需要更新推荐时，再补受影响范围的判断。结构校验只能保证说明可读，不能替助手证明推荐正确。

## 从每镜需要控制什么开始

先判断本镜最难保住的是身份、空间、起止状态、连续路径、表演、精确交互还是信息揭示；再选择足够胜任的最简单方式。普通全能参考只是选项之一。

| 控制需要 | 值得比较的方式 | 必须说明的限制 |
| --- | --- | --- |
| 主要是创意动态，画面无需精确定型 | 文生视频，审阅图可以不上传 | 不能保证具体人物或构图，必要事实要在文字中自足。 |
| 已定一幅画面作为真实起点 | 原生首帧图生 | 末态与整段路径未被锁定，不能仅靠“同图”宣称连续。 |
| 起止状态确实都需要固定 | 真实首尾帧入口 | 核实能力、时间可达性与两端几何；不要给普通参考套严格控制。 |
| 人物、道具、空间分别来自不同图片 | 多参考/全能参考 | 每份图有独立职责，不能把整组审阅状态图变成逐图落点。 |
| 动作或复杂摄影路径需要具体依据 | 运动参考视频、真实导演控制、必要预演 | 工具名称不证明实际可控制；参考只约束其支持的维度。 |
| 同空间多机位、路线、遮挡、递接 | 共用场景预演后生成 | 只做必要空间与动作，代理外观不成为正式人物或材质。 |
| 成片中只有某一镜失效 | 实际可用局部编辑/重拍或独立补镜 | 核对真实切点、两端和计费范围，长镜头不能硬拆。 |

深度图表达空间深浅与结构，不等于完整人体运动。姿态、轨迹、深度及图像身份是不同控制信号。模型和入口确有能力才用，不能把一个平台支持的参数套给另一个。

## 从逐镜判断落到可制作的生成段落

默认按“独立作品范围 → 镜头组 → 生成分组 → 声音计划”推进。用户已明确要求一次生成、逐组生成或指定组合时，优先沿用；只有真实能力、范围或费用冲突才指出具体问题。未指定生成分组时，助手根据下述标准给出一个有理由的主方案，在已有制作授权内据此准备，不额外增加分组确认。实际提交仍沿已确定的操作分工。

先确定哪些内容共同组成一部独立使用或交付的作品。按[镜头组定义](editing-sound.md#镜头组如何成立)划分完整表达单元，再以各镜头组作为生成规划的起点；镜头组本身不必等于一个生成任务，也不能为凑单次生成而改写表达组界。

- 组内镜头能用兼容的输入和控制方式实现时，优先在一次生成中完成，不机械逐镜拆任务。
- 跨组内容短、衔接紧密，且共用输入/控制方式确有利于连续性或成本时，可以合并生成，简述合并理由。仅仅同属一个作品、同一场景或平台时长装得下，不足以决定合并。
- 不同组承担独立的信息发展、场景或动态控制差异较大，或分别调整能减少重做时，优先分别生成。把接点、共用素材、声音和组间状态交代清楚，不必等到平台超时才考虑拆分。
- 单组因真实时长或控制限制需要分段时，保留该组表达与跨段接点；一次连续镜头无法保证接续时，说明限制和可行方案，不冒称拆后仍然无缝。

在现有生成建议中列出每个任务覆盖的组/镜头、预计内容时长与简短理由，使整部作品的任务范围无遗漏、无无意重复；不另建分组审批表。一次任务实际只使用入口支持的模式、模型和输入组织，不能假装每镜都能切一套互不兼容的模式。分组确定后，再按[声音计划](sound-plan.md)判断同一作品总共需要几条生成素材；不能用一次请求、当前节点或返回文件数重新定义作品范围。

比较成本时，先说可观察的准备量、生成条数和总秒数，再用真实入口可得价格估算；没有可靠价格写未知。不要用虚构成功率、固定折扣或“越便宜越好”取代表达判断。同一难点持续失败要回查设计与输入，不能只靠多次生成摊薄问题。

同一作品只有部分镜头需要预演时，可局部制作，共用空间和已有资产。所选平台确实能同时消费这些输入时，一个生成包可混合预演与图文依据；否则说明实际拆分。声音范围仍按这个独立作品真正要生成的素材条数，不按预演辅助文件或重试数判断。

生成建议提出推荐，只有用户的实际选择才成为[投产路线决定](video-production.md#本批投产路径选择门)。同一范围已有选择直接执行；输入或成本实质超出原授权时只处理新增部分。
