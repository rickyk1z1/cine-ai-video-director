# 逐镜可执行性复核

用于检查一镜内部的观看任务、动作、摄影和时间能否共同成立。首次设计覆盖本次新稿；局部修订覆盖被改镜头、前后接点和直接依赖，不机械重走整段流程。整段表达读[分镜设计](storyboard-development.md)，图序与衔接读[连续性审查](continuity-review.md)，同一问题不重复写三份结论。

## 1. 先确定三层单位

- **镜头**是一段连续摄影机画面。推拉、摇移、移焦、调度和多个动作节拍可以共存，但开始到结束的路径须清楚。
- **镜头组**由一个或多个镜头共同完成事件、关系或情绪变化，硬切明确体现在相邻镜头的起止中。
- **生成包**按实际入口承载一镜或多镜，不等于镜头编号；同镜多张状态图也不增加镜头数或任务数。

“先看纸面文字，再看表情，然后看窗外”尚未完成摄影设计。选择可执行的拉开、转向或移焦路径，或明确切镜，不能把“推进或切特写”两种互斥拍法一起交给生成者决定。

## 2. 对每镜作具体判断

按[创作尺度](storyboard-development.md#创作与复核尺度)保留写实、主观、抽象或非现实表达，只针对本镜检查有关项，不把所有作品修成同一拍法。

| 方面 | 需要作出的判断 |
|---|---|
| 观看重点 | 必须认出的对象、文字、关系或反应，在画面中是否有足够尺度、时序和注意力；可自主发现的内容不必强行集中到唯一中心 |
| 摄影路径 | 从开始到结束怎样移动或改变注意，景别、视角、焦点与遮挡能否成立；真实机位有空间依据，虚拟机位有明确变化规则和实现依赖 |
| 动作与因果 | 来向、走位、目标、身体朝向、目光、物件来源去向及停止条件是否明确；同步与先后动作分清，不隐藏换手、换装或时间跳跃 |
| 场景动态 | 人物、物体和环境怎样随时间活动，是否符合处境；固定机位不等于背景冻结，具体看[场景动态调度](staging.md#场景自身的动态也是调度) |
| 时间 | 以正常速度动作、实际声音或明确暂估为依据；并行活动、跨镜持续动作不重复累加，必要对白和辨认时间不能被挤掉；合理区间与当前选定值是否一致，是否混入无依据停顿或平台裁切余量 |
| 输入条件 | 实际角色、场景、物件状态和声音能支持哪些判断，还缺什么；风格参考不证明空间，静态可接不证明动态成功 |

让动作可执行需要足够细节，不需要逐关节、逐小数秒微操。先保留人物目的、关键动作顺序和必要完成条件；普通衔接让表演自然展开。若要求反馈在接物、到达或装配完成后出现，要以可见事件触发，时间预算不能代替事件条件。

发现冲突时可调整调度或注意时序、明确非现实变化、精简无作用动作、拆镜或补具体输入。保留合理长镜头与必要表演，不把“少写动作”当作统一修法。拍摄术语不足以确定画面时，补实际关系而非更多形容词。

## 3. 拆镜与修订操作

只有存在真实切点或观看需求才拆镜。首个承接镜沿用原稳定身份，新增镜使用无冲突的新身份，显示顺序与身份分开；其余编号遵循现有工作台约定。每个新镜各自写清观看作用、构图、动作、起止和切点，不能复制同一串动作到多个镜号。

核对整段原文与台词无丢失或重复，台词可跨镜连续。重算播放总长，更新受影响状态图、素材关系及当前提示词，历史实际任务保持原样。并发或人工内容冲突按现有修订机制回读处理，不强推覆盖。

校准预计时长时，将选定值直接写入当前duration，与必要的动作、摄影、声音、首尾及切点文字在同一次修订保存；不只另列一个更短建议而保留旧20秒内容表。只改时间估计且静帧所表达的状态未变时，保留原采用图。生成包另外说明内容长度与平台档位、余量和可裁区间；检查不能只看各段恰好凑满平台总秒数。具体方法与接口见[内容时长校准](editing-sound.md#内容平台时长与裁切余量)。

用户要求分析时提出具体建议；用户已要求修改同一范围时完成必要联动，不因拆镜或改文字重新索要开工确认，也不擅自增加新业务内容。

## 修复必须落实到产物

在已有授权内，发现问题后修订当前文字与受影响产物，再检查接点和时间。不要只在备注写“待修”却将原问题作为合格稿交付。外部实物、空间或排演材料确实缺失时，说明具体影响和可继续部分，不把局部依赖扩大为整段停工。

## 4. 可交接程度与最小证据

用已有备注简短写本次覆盖、具体处理及未验证项，例如“03 的两次观察无法在原时长内读清，改为先看警示灯、转头时揭示门外；仍待实际提示音确认切点”。不增加评分表，也不以“全部通过”替代依据。

- **文字初稿可审阅**：镜头边界与动作摄影清楚，时长有依据，假设和缺项可见。
- **图片输入可使用**：每幅图对应确定静态时刻，已有参考适用，缺资产时明确是授权内探索还是正式派生。
- **视频输入可交接**：关键动态、真实切点、时间和声音已落实，且所选入口能承载本次输入。最终准确文本、附件与参数按[出稿协议](prompt-delivery-check.md)统一复核。

这三个判断服务不同产物，不是每个任务都要经过的三道门。程序能核对结构、版本和依赖，专业可执行性仍要由助手判断；实际静帧、视频播放、声音与现场条件按任务分别验证。

## 5. 行为验证例（期望边界，不是固定答案）

| 情形 | 合理判断 |
|---|---|
| 同桌全景中拿杯、饮用、放回，时间充足 | 保留连续表演，动作多不自动拆 |
| 很短时间内读清照片、看表情、转头、再辨认远处建筑 | 查观看与时间冲突；选择调度、取舍或拆镜后重新估时，不能只增加镜号 |
| 纸页近景拉开，同时要求人物和远处字牌始终清晰 | 查距离、光学与注意力；选明确焦点次序、相容的深焦设计或切镜，不混写互斥要求 |
| 一镜穿越实体障碍并绕行后立即看清远处人脸 | 真实拍法须有路径与时间，虚拟拍法须有可辨变换；“电影感”不能代替设计 |
| 三镜提交一次生成 | 保留三镜及切点，根据真实入口编包，不改成假长镜头 |
| 静帧已经完成，但视频要求拍物件从无到有的过程 | 分清静态结果与动态过程，补必要起态/过程依据，不把所有图逐幅锁定 |

### 首稿构思的行为验证例

| 情形 | 合理判断 |
|---|---|
| 固定讲述先讲设备、后讲体验，要求有创意 | 核心信息在需要时可辨，创意不挤掉机制与体验 |
| 情绪短片要求最后揭示物件 | 保留延迟揭示，不套解释片先展示对象的顺序 |
| 总长压缩，人物关系只剩主角不同角度 | 先使交流对象与回应可感知，再调整节奏，不机械补反打 |
| 风格为夸张舞蹈或梦境 | 保留动作与形式规则，检查其可读性，不按日常自然表演删改 |
| 后续服装已备好，剧情此时尚未换装 | 依当前剧情阶段选资产，素材准备不改变故事顺序 |
| 用户只改一处眼神或持物状态 | 同步相关图与文字、检查前后接点，保留其他已采用内容和授权 |
